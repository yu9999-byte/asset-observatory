Crypto API Endpoints API Endpoint Description /api/global/ Get global crypto statistics, including the total count of coins, overall market capitalization, BTC dominance, total trading volume, ATH market capitalization, and more. /api/assets/ Lightweight list of all coins (id, symbol, name, nameid, rank). Ideal for building lookup tables, autocomplete, and coin pickers without heavy pagination. /api/tickers/ Retrieve tick data for multiple crypto coins, sorted by market cap. Includes name, ID, symbol, price, price change, market cap, volume, and supply for each ticker. /api/movers/ Top 20 winners and top 20 losers filtered by minimum $50k 24h volume. Sortable by 1h, 24h (default), or 7d price change. /api/ticker/?id={ID} Retrieve tick data for a specific coin using the ID from /api/tickers/.
